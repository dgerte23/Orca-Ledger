# Orca-Ledger
（中文见下方）Chinese RMB bookkeeping software by YINB
YINB开发的中国人民币记账软件

# English

This software will most likely not be maintained.

This is a Chinese RMB bookkeeping app. The interface, text and currency units are all Chinese-oriented. Non-Chinese users, use with caution.

1. Features

You can set the date, add a note, choose income or expense, and pick a category from the built-in list.

Income categories:Salary / Bonus / Investment / Part-time job / Red packet / OtherExpense categories:Food / Transport / Shopping / Entertainment / Housing / Medical / Study / Other

These cover most parts of a Chinese person's daily life. If nothing fits, just choose Other.

2. UISimple and clean, Chinese UI. Money is shown in ¥ (RMB) — because it is a RMB bookkeeping app, obviously.

3. How to useAdd a record → pick date → pick income/expense → pick a category → write a note (optional) → save. That's all.

4. Known bugs / limitationsThe developer is a LazinessBro, so bugs may exist. If you find one, congratulations — you can keep it.5. DisclaimerNo data is collected. Everything stays on your device. Completely free.

# 中文

本款软件大概率不会继续维护。

这款软件是一个中国人民币记账软件，界面、文字、单位均为中国的。非中国人慎用。

1. 功能

你可以选择创建时间，备注这笔账，选择支出或者收入，自带几种类型供选择。

收入类型有：工资 / 奖金 / 理财 / 兼职 / 红包 / 其他

支出的类型有：餐饮 / 交通 / 购物 / 娱乐 / 居住 / 医疗 / 学习 / 其他

这几个方面覆盖了中国人的大部分生活，如果没有相对应的，也可以选择其他。

2. 界面简洁干净，中文界面。金额单位为 ¥（人民币）——毕竟是人民币记账软件，这很合理。

3. 使用方法添加一笔记录 → 选时间 → 选收入/支出 → 选类型 → 写备注（可不写）→ 保存。就这么简单。

4. Bug开发者是一个 LazinessBro，可能存在 Bug。如果你发现了，恭喜你——这个 Bug 归你了。5. 声明不收集任何数据，所有记录保存在你的设备上。完全免费。
